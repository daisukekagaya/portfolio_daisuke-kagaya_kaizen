作品詳細

DETAIL

PROJECT

加賀谷楽器店
Webサイト(架空)

Webサイト(レスポンシブ非対応)

2024年8月(訓練開始4ヶ月目)

ターゲット

音楽を趣味として始めたい人、経験豊富な音楽家

制作目的

はじめての方にも音楽を楽しんでもらえるようなサポート体制や、鳴らしやすい楽器を用意することで、新規のお客様の獲得や既存のお客様のリピート率を上げて売り上げを増やしていくこと。

コンセプト

あなたに寄り添う楽器店

作品概要

音楽を趣味とする方やそれを生業とする方と共に歩んでいく楽器店「加賀谷楽器店」のWebサイトを制作させていただきました。これから音楽を始めたい方にとって楽器店に入店するのにもハードルが高いと言われていますが、はじめての方でも入りやすい楽器店を想像してもらえるように制作をしました。はじめての方には安価かつ性能の良い楽器やアフターサービスのご提供、経験者の方にはより音楽に集中できる楽器の調整など、幅広い客層に寄り添うことができるように「あなたに寄り添う楽器店」をコンセプトとしました。

デザイン

幅広いお客様にとって入りやすい楽器店であり、お客様に寄り添う温かみを表現するために、肌色掛かったカラーをベースとして制作しました。初心者の方が音楽を始めるにあたって、こういう楽器店がサポーターとして寄り添い、初心者向けの方の楽器の用意や調整・レッスンなどのアフターサービスもあるということを順を追ってお伝えできるような構成にしております。

制作時間

企画・ワイヤーフレーム:2時間
デザイン:2時間
コーディング:5時間

使用ツール

Figma / Adobe PhotoShop / VisualStudio Code
