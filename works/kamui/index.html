作品詳細

DETAIL

PROJECT

KAMUY MINAMI MARUYAMA
Webサイト(架空)

Webサイト(レスポンシブ非対応)

2024年8月(訓練開始4ヶ月目)

ターゲット

特別な時間を過ごしたい20～40代の夫婦やカップル。

制作目的

料理の画像を多く取り入れることでWebサイト上からでも料理の雰囲気がわかるようにする。
ハレの場で使っていただけるような特別感や高級感を伝えることができるようにする。

コンセプト

特別な時間

作品概要

フランス料理をベースとしながらも、北海道の食材と日本の文化を料理に取り込むことで、独自の世界観を生み出すフレンチレストラン「KAMUY MINAMIMARUYAMA」様のWebサイトを制作しました。

デザイン

レストランであるため、ファーストビューには料理の画像を配置しています。ハレの場として使っていただけるような特別感や高級感をWebサイトから感じていただけるように、セクション間の余白を多めに取り、デザインの装飾を付けないことで高級感を演出しています。また、料理の画像を多く配置し、レストランンの雰囲気ではなくあくまで料理でお客様に満足していただけるようなWebサイトになるように仕上げました。　

制作時間

企画・ワイヤーフレーム:2時間
デザイン:2時間
コーディング:5時間

使用ツール

Adobe XD / Adobe PhotoShop / VisualStudio Code
