作品詳細

DETAIL

PROJECT

株式会社ネクストワン札幌支社
Webサイトリニューアル

Webサイト(レスポンシブ非対応)

2024年8月(訓練開始4ヶ月目)

ターゲット

Webデザインに興味があり、転職を考えている20～30代の男女。

制作目的

株式会社ネクストワン札幌支社がどんな事業の会社なのかが伝わるWebサイトにする。
未経験からでもWebデザイナーを目指すことができる職業訓練校を運営していることを伝える。

コンセプト

再出発

作品概要

職業訓練校ウェブスタディサッポロを運営している、株式会社ネクストワン札幌支社様のサイトをリニューアルをさせていただきました。コンセプトである再出発は自分自身が訓練校で学ぶ上での考え方でもあり、全く違う職種からの新たな出発という意味も込めて再出発としました。

デザイン

人生を改めて再出発するという意味も込めて、何色にも染まっていない白を基調としたカラーとしています。装飾のないシンプルなサイト構成となっていますが、今は何もなくてもこれからWeb制作における様々な知識を吸収していくという意味合いで、あえてシンプルなデザインにしております。また、サイトを開くと現れるMVのアニメーションですが、自分で「RESTART」とタイピングすることで決意を新たにするという意味を込めています。

制作時間

企画・ワイヤーフレーム:2時間
デザイン:2時間
コーディング:5時間

使用ツール

Adobe XD / Adobe PhotoShop / VisualStudio Code
