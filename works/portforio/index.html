PROJECT

ポートフォリオサイト

Webサイト(レスポンシブ非対応)

2024年9月(訓練開始5ヶ月目)

ターゲット

企業の採用担当者様。

制作目的

なぜWeb業界に転職をしたいのか、当サイトのテキストや制作物を通してお伝えし、少しでも興味を持っていただけるようにするため。

コンセプト

継続は力なり

作品概要

大学を卒業してから11年間を回転寿司店で働き、お客様に美味しいと思っていただけるように地道に技術を磨いてきました。これまでの自分の生き方を振り返ると、上手くいかない・できないことの連続でしたが、目標に向かって途中で投げ出すことなく取り組んできたと思います。「継続は力なり」という言葉を忘れることなく、これからも学び続けていきたいと思い、このようなこのコンセプトにしました。

デザイン

継続していくことにはエネルギーや力強さが必要であると思います。そういったものを表現するために太く黒いラインを引き、キャッチコピーにゴシック体の太いフォントを使用しました。またMVの年輪は地道ではあるもののひとつひとつ着実に幹を太くして成長していく様を表現するために、このような画像を使用しております。

制作時間

企画・ワイヤーフレーム:10時間
デザイン:15時間
コーディング:15時間

使用ツール

Figma / Adobe PhotoShop / VisualStudio Code
