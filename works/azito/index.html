作品詳細

DETAIL

PROJECT

cafe azito
Webサイトリニューアル

Webサイト(レスポンシブ非対応)

2024年8月(訓練開始4ヶ月目)

ターゲット

非日常を感じてリラックスをしたい20~40代の女性・カップル・夫婦 。

制作目的

店舗で感じることができるリゾート感や非日常感をWebサイトからでも感じることができるようにリニューアルし、新規のお客様を増やして売り上げを伸ばすこと。

コンセプト

非日常感

作品概要

海の爽やかな風と、寄せては返す波の音を感じるコンセプトカフェ「cafe azito」様のサイトをリニューアルいたしました。日常生活では感じることのできない非日常感、リゾート感をWebサイトからも感じていただけるように制作しました。

デザイン

海のすぐそばにあるリゾート感漂うカフェであることから海のさわやかさを感じさせる淡いブルーをベースにした色合いとし、画像にもやや青みがかったような加工をしております。文字は行間をやや多めに取り、余白も広めに取ることでリゾートならではのくつろぎ感を出せるようにしました。ボタンのホバーアニメーションは寄せては返す波を表現しています。

制作時間

企画・ワイヤーフレーム:2時間
デザイン:2時間
コーディング:5時間

使用ツール

Adobe XD / Adobe PhotoShop / VisualStudio Code
